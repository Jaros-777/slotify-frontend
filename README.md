# Slotify frontend

## 🛠 Technologies  
- React  
- TypeScript  
- Tailwind  

## 🚀 Getting Started  
This section explains how to run the Slotify Frontend project locally.  

### ✅ Prerequisites  
- Make sure you have the following installed:  
- Node.js (version 18 or later)  
- npm or yarn  
- (optional) Git, if you want to clone the repository  
### 📦 Installation  
1. Clone the repository:  
`git clone https://github.com/Jaros-777/slotify-frontend.git`
  
2. Navigate to the project directory:  
`cd slotify-frontend`
  
3. Install dependencies:  
`npm install or yarn install`  
 
4. 🖥️ Running the development server  
`npm run dev`

The app will be available at:
👉 http://localhost:5173
